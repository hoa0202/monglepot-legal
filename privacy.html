게임 기록과 설정

회원가입이나 로그인은 없으며 게임 이용을 위해 이름·전화번호·이메일을 입력받지 않습니다. 플레이 인원, 효과음·진동·화면 방향 설정, 총 플레이 횟수, 개인 최고기록, 최근 게임의 종류·인원·결과·시각을 기기에 저장합니다. 목적은 설정을 유지하고 자신의 게임 기록을 보여 주는 것입니다.

현재 게임 코드에는 이 기록과 설정을 운영자 서버에 전송하거나 다른 이용자와 공유하는 기능이 없습니다. 운영자 자체 서버와 별도 분석·오류 수집 SDK는 추가하지 않았습니다. 이는 게임 자체의 처리 설명이며, 포함된 광고 SDK의 모든 실행 시점에 외부 통신이나 수집이 없음을 검증했다는 뜻은 아닙니다.

iPhone 로비 배너 광고와 설정

광고 연결 코드는 앱에 포함된 활성 설정과 몽글팟 전용 광고단위가 유효한 경우에만 광고 요청을 진행합니다. 설정이 꺼져 있거나 광고단위가 비어 있으면 광고 객체 생성과 광고 요청을 진행하지 않습니다. 광고 설정을 가져오는 원격 조회 기능은 없으며, 광고 설정 조회를 위해 IP 주소를 서버로 전송하는 기능도 추가하지 않았습니다.

광고가 비활성인 버전에서 활성화하려면 몽글팟 전용 광고단위를 확인하고 설정을 바꾼 후속 앱 업데이트가 필요합니다. 서버 설정만으로 나중에 광고를 켜는 구조는 아닙니다. SDK 포함과 실제 광고 요청 여부는 구분합니다. SDK의 모든 실행·통신에 대한 검증을 마쳤거나 데이터 수집이 전혀 없다고 안내하지 않습니다.

광고 활성 버전에서는 유효한 앱 전용 설정과 iOS 앱 추적 투명성(ATT) 허용이 모두 있어야 홈·게임 선택 로비 상단의 배너를 요청하도록 구현되어 있습니다. 게임 플레이 중에는 광고를 표시하지 않습니다. 추적을 거부해도 게임을 이용할 수 있으며 허용 여부는 iOS 설정에서 변경할 수 있습니다. 광고 활성화 전에는 실제 처리와 이 안내를 다시 검토합니다.

보관과 삭제

기록과 설정은 iOS 앱 저장 공간(UserDefaults), Android 앱 저장 공간(SharedPreferences), 웹 브라우저의 사이트 저장 공간에 보관됩니다. 설정 → 기록 초기화를 선택하면 최고기록과 플레이 내역을 지웁니다. 효과음·진동 등 설정은 유지됩니다. 앱을 삭제하거나 브라우저의 사이트 데이터를 지우면 해당 저장 데이터도 삭제됩니다.

기기 백업·복원을 사용하면 운영체제와 사용자의 백업 설정에 따라 이전 데이터가 복원될 수 있습니다. Android 백업 대상은 게임 기록·설정 파일이며 WebView 캐시와 앱 내부 실행 경로는 제외합니다. 운영자는 기기에만 저장된 기록을 원격으로 열람·수정·복구할 수 없습니다. 브라우저·iPhone·Android 기록은 자동으로 동기화되지 않습니다. 광고 SDK가 처리할 수 있는 정보의 보관·삭제 조건은 공급자 정책과 실제 처리에 따라 달라집니다. 관련 요청은 아래 문의 창구로 보내 주시면 해당 처리 주체를 확인하고 안내하겠습니다. 확인하지 않은 보관 기간을 확정적으로 표시하지 않습니다.
